# CloseCircle Web

Rede social privada baseada em círculos, amizades, mensagens e eventos colaborativos.

## Arquitetura planejada

- Next.js + TypeScript + Tailwind CSS
- Neon PostgreSQL + Drizzle ORM
- Better Auth para autenticação
- Vercel para deploy
- Armazenamento privado de mídia com URLs assinadas

## Princípios

- Conteúdo privado por padrão.
- Autorização validada no servidor para cada leitura e escrita.
- Nenhum segredo no Git.
- Ambientes de desenvolvimento e produção isolados.
- Versão corporativa futura com isolamento por organização.
